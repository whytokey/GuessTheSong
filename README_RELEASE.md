# 5 секунд — сборка 3.0.1

## В составе

- `index.html`, `game.js`, `style.css` — клиент игры.
- `catalog.json` — предоставленный музыкальный каталог.
- `multiplayer.test.cjs` — локальный набор регрессионных тестов без сетевых запросов.

## Запуск и публикация

1. Разместите все четыре игровых файла в одном каталоге на HTTPS-хостинге. Не открывайте игру как `file://`: браузеру нужен HTTP(S), чтобы загрузить каталог и аудио.
2. Сохраните на хостинге каталог `music/` с теми MP3, на которые ссылается `catalog.json`. Пути в записи каталога относительные, например `music/1.mp3`. Сервер должен отдавать аудио с корректным `Content-Type` и поддержкой byte-range запросов.
3. Убедитесь, что Realtime Database Firebase из конфигурации `game.js` доступна из окружения публикации и ее правила разрешают необходимые операции игры. Ошибка доступа теперь показывается отдельно от отсутствующей комнаты.
4. Все участники должны загрузить одну версию игры. Комнаты предыдущего протокола несовместимы: создайте новую комнату после обновления клиентов.
5. Проведите контрольный матч: создать пользовательскую комнату, подключить еще двух участников по шестизначному коду, начать матч и проверить счет в нескольких раундах. Затем повторите с кратким отключением участника.

**Безопасность Firebase:** клиентская реализация не является античитом и сама по себе не может обеспечить безопасные права доступа или защиту счета. Не публикуйте базу с безусловными правилами чтения/записи. Перед открытым релизом проверьте и настройте правила Realtime Database/аутентификацию для своего проекта; конфигурацию и действующие правила владельца нельзя подтвердить из этих файлов.

## Проверка кода

С установленным Node.js выполните в каталоге игры:

```sh
node --check game.js
node multiplayer.test.cjs
```

Набор содержит 19 детерминированных сценариев, включая создание комнаты с холодным кэшем, вход третьего игрока, гонку запуска, синхронизацию десяти раундов, ответы и таймауты, уход/переподключение хоста, временный обрыв участника, заполненную комнату, несовместимую версию, запрет Firebase и одиночный режим. Это тесты клиентской логики с тестовой RTDB, а не проверка живого Firebase.

## Что не входит в приложенные файлы

В переданных вложениях есть каталог записей, но нет самих MP3-файлов. Поэтому ZIP исходников не содержит `music/`. Если аудио уже лежит на вашем игровом хостинге, сохраняйте эту папку при публикации. Перед релизом проверьте, что все ссылки каталога доступны по HTTPS и что у вас есть необходимые права на распространение аудио.
